xmlsec1 n'est pas configuré avec LIBXML_PARSE_HUGE, ce qui provoque une erreur pour les fichiers
dont un noeud fait plus de 10 Mo.

La procédure suivante permet de recompiler xmlsec1 l'option LIBXML_PARSE_HUGE positionné.


0) Préparer la plateforme
sudo apt-get install libxml2-dev
sudo apt-get install libxslt-dev
sudo apt-get install libtool-dev
sudo apt-get install libtool


1) Récupérer les sources d'openssl
 wget https://www.openssl.org/source/openssl-1.0.2e.tar.gz

2) Compiler Openssl en mode shared
tar xvzf openssl-1.0.2e.tar.gz
cd openssl-1.0.2e/
export CFLAGS=-fPIC
./config shared
make
sudo make install

3) Compiler xmlsec1
Modifier src/parser.c => décommenter la partie LIBXML_PARSE_HUGE
./configure --with-openssl=/usr/local/ssl
make

4) Configurer TedetisPHP (en adaptant)
define("XMLSEC1_PATH","export LD_LIBRARY_PATH=/home/eric/Logiciel/xmlsec1-1.2.20/src/openssl/.libs && /home/eric/Logiciel/xmlsec1-1.2.20/apps/xmlsec1");

5) Test

php test/helios/vetification-signature.php gros-pes.xml
(doit afficher Vérification: OK)
